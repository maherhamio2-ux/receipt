# نظام استلام المبالغ — Local First + Vercel

نسخة 3.0 من النظام بواجهة عربية RTL، تعمل على الهاتف والحاسوب، ويقوم **المتصفح نفسه بحفظ البيانات** باستخدام IndexedDB بدل قاعدة بيانات Supabase.

## ما الذي تغيّر؟

- لا توجد قاعدة بيانات خارجية.
- لا يحتاج النظام إلى Supabase أو مفاتيح قاعدة بيانات.
- الأسماء، العمليات، الإلغاءات، الإعدادات، المستخدمون وسجل التدقيق محفوظة في IndexedDB على الجهاز والمتصفح الحاليين.
- الاسم غير الموجود يُضاف تلقائيًا عند أول عملية.
- لكل عملية رقم فريد مثل `REC-20260913-000001`.
- لا يوجد حذف نهائي للعمليات؛ الإلغاء يحتاج سببًا ويُحفظ اسم الموظف والوقت والسبب.
- النظام ينشئ نسخة محلية داخل المتصفح كل 24 ساعة ويحتفظ بآخر 7 نسخ محلية.
- من الإعدادات يمكن تنزيل نسخة احتياطية JSON كاملة واستعادتها لاحقًا.
- يوجد زر لطلب Persistent Storage من المتصفح لتقليل احتمال حذف البيانات تلقائيًا.
- يمكن استيراد أسماء من Excel/CSV.
- تسجيل الدخول محلي؛ في أول تشغيل ينشئ المستخدم حساب المدير، ويمكن للمدير إضافة موظفين آخرين.
- كلمات المرور لا تُخزّن كنص واضح؛ يتم اشتقاق Hash باستخدام PBKDF2/SHA-256 وsalt منفصل.

## مهم جدًا بخصوص البيانات المحلية

البيانات مرتبطة **بنفس المتصفح + نفس الجهاز + نفس نطاق الموقع**. فتح النظام من جهاز آخر لا يعرض بيانات الجهاز الأول تلقائيًا.

مسح بيانات الموقع من إعدادات المتصفح قد يحذف قاعدة IndexedDB. لذلك استخدم زر **تنزيل نسخة JSON** بشكل دوري واحتفظ بها في مكان خارجي.

النسخ المحلية التلقائية مفيدة للرجوع داخل نفس قاعدة المتصفح، لكنها تُمسح أيضًا إذا تم حذف بيانات الموقع بالكامل.

## البريد وواتساب

- واتساب: يفتح النظام محادثة الرقم المحدد مع نص الرسالة جاهزًا.
- البريد: يفتح تطبيق البريد الافتراضي باستخدام `mailto:` مع العنوان والنص جاهزين.
- لا تُرسل البيانات المالية إلى سيرفر بريد من داخل هذه النسخة.

## تشغيل المشروع محليًا

```bash
npm install
npm run dev
```

## النشر على Vercel

1. ارفع المشروع إلى GitHub.
2. أنشئ Project جديدًا على Vercel واختر المستودع.
3. لا تحتاج إلى Environment Variables لقاعدة البيانات.
4. اضغط Deploy.
5. عند أول فتح للنظام أنشئ حساب المدير.

## النسخ الاحتياطي

من **الإعدادات > البيانات والنسخ الاحتياطي**:

- طلب التخزين الدائم.
- إنشاء نسخة محلية الآن.
- تنزيل نسخة JSON.
- استعادة نسخة JSON.
- عرض المساحة المستخدمة وآخر نسخة وعدد النسخ المحلية.

## بنية التخزين

يستخدم النظام Object Stores منفصلة داخل IndexedDB:

- `people`
- `receipts`
- `settings`
- `users`
- `audit`
- `meta`
- `backups`

## الأمان

هذا نموذج Local First. الحماية الفعلية تعتمد أيضًا على حماية الهاتف/الحاسوب والمتصفح وحساب المستخدم في الجهاز. إذا كان الجهاز مشتركًا بين عدة أشخاص، فعّل قفل الجهاز واستخدم كلمات مرور قوية للحسابات داخل النظام.


## تثبيت النظام كتطبيق PWA

أضيف زر سهم للتثبيت في الشريط العلوي. عند توفر تثبيت PWA في المتصفح، الضغط عليه يفتح نافذة التثبيت مباشرة. بعد التثبيت يظهر النظام ضمن التطبيقات ويفتح بواجهة مستقلة دون شريط المتصفح.

- على Chrome/Edge والمتصفحات الداعمة: سيظهر مربع التثبيت مباشرة.
- على Samsung Internet: إذا لم يظهر الطلب المباشر، يعرض النظام إرشادات إضافة الصفحة إلى الشاشة الرئيسية/التطبيقات.
- على iPhone/iPad: يعرض النظام إرشادات Safari لإضافة التطبيق إلى الشاشة الرئيسية.

تمت إضافة manifest بأيقونات 192 و512 بكسل وService Worker لتلبية متطلبات تطبيق الويب القابل للتثبيت.
